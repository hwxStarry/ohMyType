# Sound Sources

These local sound effects are Mixkit preview MP3 files used as short feedback sounds.

- `keyboard-single.mp3`: Single key type, from https://mixkit.co/free-sound-effects/keyboard/
- `keyboard-hard.mp3`: Hard single key press in a laptop, from https://mixkit.co/free-sound-effects/keyboard/
- `metal-hammer.mp3`: Metal hammer hit, from https://mixkit.co/free-sound-effects/metal/
- `metal-sword.mp3`: Metallic sword strike, from https://mixkit.co/free-sound-effects/metal/
- `explosion-short.mp3`: Short explosion, from https://mixkit.co/free-sound-effects/explosion/
- `impact-plate.mp3`: Axe hits to a plate, from https://mixkit.co/free-sound-effects/metal/
