# Sound Sources

These local sound effects are Mixkit preview MP3 files used as short feedback sounds.

- `keyboard-single.mp3`: Single key type, from https://mixkit.co/free-sound-effects/keyboard/
- `keyboard-hard.mp3`: Hard single key press in a laptop, from https://mixkit.co/free-sound-effects/keyboard/
- `metal-hammer.mp3`: Metal hammer hit, from https://mixkit.co/free-sound-effects/metal/
- `metal-sword.mp3`: Metallic sword strike, from https://mixkit.co/free-sound-effects/metal/
- `explosion-short.mp3`: Short explosion, from https://mixkit.co/free-sound-effects/explosion/
- `impact-plate.mp3`: Axe hits to a plate, from https://mixkit.co/free-sound-effects/metal/

These local OGG sound effects are from Kenney Interface Sounds, licensed CC0.

- `kenney-click-001.ogg`: click_001.ogg, from https://kenney.nl/assets/interface-sounds
- `kenney-select-001.ogg`: select_001.ogg, from https://kenney.nl/assets/interface-sounds
- `kenney-confirmation-001.ogg`: confirmation_001.ogg, from https://kenney.nl/assets/interface-sounds
- `kenney-pluck-001.ogg`: pluck_001.ogg, from https://kenney.nl/assets/interface-sounds
- `kenney-tick-001.ogg`: tick_001.ogg, from https://kenney.nl/assets/interface-sounds
- `kenney-switch-001.ogg`: switch_001.ogg, from https://kenney.nl/assets/interface-sounds
- `kenney-bong-001.ogg`: bong_001.ogg, from https://kenney.nl/assets/interface-sounds
- `kenney-glitch-001.ogg`: glitch_001.ogg, from https://kenney.nl/assets/interface-sounds

The retro game-style presets are generated at runtime with the Web Audio API. They do not use original game audio assets.
